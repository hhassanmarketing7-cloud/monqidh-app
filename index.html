منصة خدمات الفنيين والحرفيين

مستند متطلبات المنتج (PRD) - الإصدار الحالي: MVP v1.0

نظرة عامة

منصة خدمية رقمية عربية شاملة تربط أصحاب الحرف والفنيين المستقلين بالعملاء الباحثين عن خدمات منزلية ومهنية.

الميزات المنجزة ✅

  • البنية التحتية: Backend API بـ FastAPI، قاعدة بيانات MongoDB، ونظام مصادقة JWT.
  • للعملاء: تصميم عصري، فلترة جغرافية ذكية، بطاقات الفنيين، وزر اتصال مباشر.
  • للفنيين: صفحات تسجيل جديد، تسجيل دخول، وملف شخصي متكامل.
  • البيانات التجريبية: دعم 5 دول عربية، محافظات متعددة، وفنيين تجريبيين.
  • الإدارة: واجهات برمجة التطبيقات (API endpoints) لإدارة ومتابعة الفنيين.

الميزات قيد التطوير 🚧

  • واجهة ويب لوحة تحكم الإدارة (Admin Panel).
  • نظام الاشتراكات والدفع الإلكتروني عبر Stripe.
  • تطوير تعديل الملف الشخصي للفنيين ورفع الصور.
  • نظام الإشعارات والبحث المتقدم.
حالة المشروع: قيد التطوير النشط لتطبيقات الموبايل والويب.
